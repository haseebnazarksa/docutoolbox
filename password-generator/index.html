What makes a strong password?

A strong password is long, random, and uses a mix of character types, uppercase, lowercase, numbers, and symbols, making it resistant to both guessing and brute-force attacks. This tool generates passwords using your browser's cryptographically secure random number generator, not a predictable pattern.

How to use this generator

  1. Set your desired length using the slider (longer is stronger).
  2. Choose which character types to include.
  3. Click Generate new password, or adjust any setting to auto-regenerate.
  4. Click Copy to copy the password to your clipboard.

Password length guidance

  • Under 8 characters - weak, crackable quickly with modern hardware
  • 12-16 characters - reasonable for most everyday accounts
  • 20+ characters - strongly recommended for sensitive accounts (banking, email, password managers)

Using a unique password for every account, ideally stored in a password manager, matters as much as password strength itself.

Frequently asked questions

Is this password sent anywhere or logged?

No, passwords are generated entirely in your browser using JavaScript's secure random number generator, nothing is transmitted to a server or stored.

Why does the strength meter matter if I use all character types?

Length has the biggest impact on password strength, a longer password with fewer character types is often still stronger than a short one with every type included.

What is this tool?

This tool builds CSS gradients visually, add color stops, adjust their position, and set an angle or shape, then see the gradient update live before copying the finished CSS code.

How to use this tool

  1. Choose Linear or Radial gradient type.
  2. For linear gradients, adjust the angle.
  3. Add, remove, or adjust color stops, each with its own color and position.
  4. Copy the generated CSS.

Linear vs radial gradients

  • Linear gradients - transition colors in a straight line at a specified angle, useful for backgrounds, buttons, and banners
  • Radial gradients - transition colors outward from a center point, useful for spotlight effects or circular color blends

Frequently asked questions

Can I use more than two colors?

Yes, click "Add color stop" to add as many colors as you need, each with its own position along the gradient.

Will this gradient work in all browsers?

Linear and radial gradients using standard CSS syntax (as generated here) are supported in all modern browsers without vendor prefixes.

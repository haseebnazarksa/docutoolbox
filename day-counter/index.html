What is the Day Counter?

The Day Counter answers a simple question: how many days is it until (or since) a specific date? Pick any date in the past or future and the tool instantly tells you how many days separate it from today.

How to use it

Select a date using the date picker. If the date is in the future, you'll see how many days remain until it arrives. If it's in the past, you'll see how many days have gone by since.

Common uses

  • Counting down to a wedding, exam, launch date, or holiday
  • Tracking how many days it's been since a milestone (quitting a habit, starting a job, a health event)
  • Planning how much time is left to prepare for a deadline

How today is determined

"Today" is based on your device's local date and time, so the count will always match the calendar day you're currently on, wherever you are.

About this toolbox

Docutoolbox is a free, growing collection of small browser-based tools — a word and character counter, a text case converter, an image compressor, an age calculator, and more being added over time.

Every tool here is built around one idea: small everyday tasks shouldn't need an account, an app download, or a file upload to a stranger's server. Type, paste, or drop a file in, get the result instantly, and move on.

Everything runs directly in your browser using JavaScript. Text you type, images you compress, and dates you calculate never leave your device — nothing is uploaded, logged, or stored anywhere.

Docutoolbox is actively maintained and new tools are added regularly based on what's genuinely useful for everyday writing, images, and calculations.

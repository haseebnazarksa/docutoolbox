What is .htaccess?

A .htaccess file is a configuration file used by Apache web servers to control URL redirects, access rules, and other server behavior on a per-directory basis, without needing to edit the main server configuration. This tool generates common redirect rules ready to paste into your .htaccess file.

How to use this tool

  1. Choose a rule type: page redirect, www/non-www, or force HTTPS.
  2. Fill in the relevant fields.
  3. Copy the generated code and paste it into your site's .htaccess file, typically located in your website's root directory.

Common uses

  • Redirecting an old page URL to a new one after a site restructure, without losing SEO value (via a 301 redirect)
  • Enforcing a single canonical domain version (www or non-www) to avoid duplicate content issues
  • Forcing all visitors to use HTTPS instead of HTTP for security

Note: .htaccess only works on Apache servers (common with shared hosting and cPanel). If your site runs on Nginx, these rules won't apply, you'd need equivalent Nginx configuration instead.

Frequently asked questions

Where do I put the .htaccess file?

In the root directory of your website (often called public_html or www on shared hosting), rules in that file apply to the entire site unless placed in a subdirectory.

Why use a 301 redirect instead of a 302?

A 301 redirect signals a permanent move, which passes SEO ranking value to the new URL and updates search engine indexes, a 302 signals a temporary redirect and doesn't transfer ranking value the same way.

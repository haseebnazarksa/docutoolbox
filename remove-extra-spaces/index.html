What is this tool?

This tool cleans up messy text by collapsing repeated spaces down to a single space, removing blank lines, and trimming stray whitespace from the start and end of each line. It's useful for text that's been copied from a PDF, website, or another source and picked up inconsistent spacing along the way.

How to use it

  1. Paste your text into the box.
  2. Choose which cleanup options to apply.
  3. Click Clean text.
  4. Copy the cleaned result.

Understanding the options

  • Collapse extra spaces - turns multiple consecutive spaces or tabs into a single space
  • Remove blank lines - deletes any completely empty lines from the text
  • Trim start/end of each line - removes leading and trailing whitespace from every individual line

Common uses

  • Cleaning up text copied from a PDF that added inconsistent spacing
  • Fixing text pasted from a website that carried over extra formatting whitespace
  • Preparing text for import into a database or spreadsheet where extra whitespace causes issues
  • Tidying up a document before final submission or publishing

Frequently asked questions

Does this remove all line breaks entirely?

No, it only removes completely blank lines and cleans up spacing within existing lines, actual paragraph breaks (lines with content) are preserved. To collapse all line breaks into one continuous line, use the Line Break Remover tool instead.

Is my text uploaded anywhere?

No, all cleanup happens locally in your browser.

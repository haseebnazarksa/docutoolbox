What are Docutoolbox's Image Tools?

This is a growing collection of free, browser-based tools for everything people commonly need to do with a photo or graphic: shrinking a file for upload, resizing it to exact dimensions, cropping it, converting between formats, or pulling out its hidden metadata. Every tool listed here runs entirely on your own device using the Canvas API built into modern browsers.

There's no software to install, no account to create, and no watermark added to your output. Open the tool you need, do the task, and download the result.

Why browser-based image tools?

Most image websites work by uploading your photo to a remote server, processing it there, and sending a result back down, which means your image briefly sits on someone else's servers. Docutoolbox's tools are built differently: the resizing, cropping, and format conversion all happen directly inside your browser using JavaScript's Canvas API, so your photo never leaves your device. This also tends to be faster, since there's no upload or download wait over a network connection.

How to choose the right tool

If your image's file is too large, reach for the Image Compressor. If you need different pixel dimensions, that's the Image Resizer, while trimming away part of a photo is the Image Cropper. Converting between file types, including from an iPhone's HEIC format, uses the Format Converter or HEIC to JPG tool. For visual effects, the Blur, Flip/Rotate, and Color Inverter tools cover the most common quick edits. And for anything technical, from reading a pixel's exact color to checking hidden EXIF metadata, the Color Picker and EXIF Viewer are purpose-built for those tasks.

Is it really free?

Yes, every tool on this page is free to use, with no page limits, no watermarked output, and no account required. Because processing happens on your own device rather than paid server infrastructure, there's no per-file cost to offset with a subscription.

Frequently asked questions

Do I need to install anything?

No, every tool runs directly in your web browser. There's nothing to download or install beyond the page itself.

Is my photo uploaded anywhere?

No. All processing happens locally in your browser using JavaScript. Your images are never transmitted to a server.

Is there a file size limit?

Each tool notes a practical size guideline, mainly because very large images take longer to process on your own device rather than a powerful remote server. There's no hard cap enforced beyond what your device's memory can comfortably handle.

Which browsers are supported?

Any modern browser, Chrome, Firefox, Edge, or Safari, on desktop or mobile will work, since these tools rely on standard JavaScript features built into all current browsers.

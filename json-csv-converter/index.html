What is this tool?

This tool converts data between JSON (a structured format common in APIs and code) and CSV (a simple spreadsheet-friendly format), in either direction. It expects JSON as an array of flat objects, converting each object into a CSV row with object keys as column headers.

How to use this tool

  1. Choose a direction: JSON → CSV or CSV → JSON.
  2. Paste your data into the input box.
  3. Click Convert.
  4. Copy the result or download it as a file.

Common uses

  • Converting an API's JSON response into a CSV file to open in Excel or Google Sheets
  • Converting a spreadsheet export (CSV) into JSON for use in code or an API
  • Preparing data for import into a different system that expects the other format

Frequently asked questions

Does this handle nested JSON objects?

This tool works best with flat JSON objects (no nested objects or arrays within each record), since CSV itself has no native way to represent nested structures. Nested values will be converted to their string representation.

What if my JSON objects have different fields?

The CSV output uses the combined set of all keys found across every object as columns, any object missing a particular field will have an empty cell for that column.

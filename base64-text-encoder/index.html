What is Base64?

Base64 is a way of representing binary or text data using only letters, numbers, and a few symbols, making it safe to include in places that only accept plain text, like JSON files, URLs, or email attachments. This tool encodes plain text into Base64, or decodes Base64 back into its original readable text.

How to use it

  1. Choose Encode or Decode.
  2. Paste your text into the box.
  3. Click Convert and copy the result.

Common uses

  • Encoding text or credentials to include in an API request or configuration file
  • Decoding a Base64 string found in code, a URL, or an email header to read its actual content
  • Embedding small text data inside JSON or XML without special characters causing issues
  • Working with authentication tokens that use Base64 encoding

Frequently asked questions

Is Base64 encoding the same as encryption?

No, Base64 is not encryption or a security measure, it's simply a different way of representing the same data, anyone can decode it back to the original text instantly. Never use Base64 alone to protect sensitive information.

Why did decoding fail?

This usually means the text isn't valid Base64, check that you've copied the complete string without missing or extra characters, and that it only contains valid Base64 characters (letters, numbers, +, /, and = padding).

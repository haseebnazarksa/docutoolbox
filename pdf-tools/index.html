What are Docutoolbox's PDF & Document Tools?

This is a growing collection of free, browser-based tools for everything people commonly need to do with a PDF - combining files, pulling pages apart, fixing orientation, converting to and from images, adding page numbers or a watermark, and removing a password from a file you already have access to. Every tool listed here runs entirely on your own device.

There's no software to install, no account to create, and no file size charged against a monthly quota. Open the tool you need, do the task, and download the result - that's the whole workflow.

Why browser-based PDF tools?

Most PDF websites work by uploading your file to a remote server, processing it there, and sending a result back down - which means your document (which might contain contracts, IDs, financial statements, or other private information) briefly sits on someone else's servers. Docutoolbox's tools are built differently: the PDF libraries that do the actual work (pdf-lib and pdf.js) run directly inside your browser using JavaScript, so your file never leaves your device. This also tends to be faster, since there's no upload or download wait over a network connection - everything happens locally at the speed of your own computer.

What each tool does

  • Merge PDF - combine multiple PDFs into one, with full control over page order via drag-and-drop thumbnails
  • Split PDF - pull specific pages out of a PDF, either combined into one new file or as separate files
  • PDF Page Rotator - fix pages that scanned in sideways or upside-down, individually or all at once
  • PDF to JPG / PNG - export every page of a PDF as a standalone image file
  • JPG / Image to PDF - combine one or more images into a single PDF document
  • PDF Page Numbers - stamp page numbers onto every page, with control over position, format, and starting number
  • PDF Watermark - add a custom text watermark (like "DRAFT" or "CONFIDENTIAL") across every page
  • Unlock PDF - remove password protection from a PDF you already know the password for

More tools - including PDF to Word, Word to PDF, Compress PDF, Protect/Lock PDF, OCR text extraction, digital signing, and Excel conversion - are in active development and will appear here as they're finished.

How to choose the right tool

If you're not sure which tool fits your task, think about what you're starting with and what you need to end up with. Combining several PDFs into one document is a job for Merge PDF. Pulling a few pages out of a longer document is Split PDF. Turning pages into pictures - for a slideshow, a social post, or embedding elsewhere - is PDF to JPG/PNG, while going the other direction, turning photos or scans into one PDF, is JPG/Image to PDF. If a page looks sideways, that's the Page Rotator; if you need a document professionally numbered or stamped with a "DRAFT" label, that's Page Numbers or Watermark; and if you're locked out of editing a PDF you already have the password for, that's Unlock PDF.

Is it really free?

Yes - every tool on this page is free to use, with no page limits, no watermarked output, and no account required. Because processing happens on your own device rather than on paid server infrastructure, there's no per-file cost to offset with a subscription.

Frequently asked questions

Do I need to install anything?

No - every tool runs directly in your web browser. There's nothing to download or install beyond the page itself.

Is my file uploaded anywhere?

No. All processing happens locally in your browser using JavaScript. Your files are never transmitted to a server.

Is there a file size limit?

Each tool notes a practical size guideline (typically around 50MB), mainly because very large files take longer to process on your own device rather than a powerful remote server. There's no hard cap enforced beyond what your device's memory can comfortably handle.

Which browsers are supported?

Any modern browser - Chrome, Firefox, Edge, or Safari - on desktop or mobile will work, since these tools rely on standard JavaScript features built into all current browsers.

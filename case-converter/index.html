What is the Case Converter?

This tool converts text between eight common capitalization styles instantly, from everyday formats like UPPERCASE and Title Case to programming conventions like camelCase and snake_case.

How to use it

  1. Type or paste your text into the box.
  2. Click any case button, the text updates instantly in that format.
  3. Click Copy result to copy the converted text.

The eight case styles

  • UPPERCASE - all letters capitalized
  • lowercase - all letters lowercase
  • Title Case - first letter of each word capitalized
  • Sentence case - only the first letter of each sentence capitalized
  • camelCase - likeThis, common in JavaScript variable names
  • PascalCase - LikeThis, common for class names in code
  • snake_case - like_this, common in Python and database fields
  • kebab-case - like-this, common in URLs and CSS classes

Common uses

  • Fixing text that was accidentally typed with Caps Lock on
  • Formatting headlines and titles correctly
  • Converting a phrase into a valid variable or file name for code
  • Preparing consistent capitalization for a spreadsheet or dataset

Frequently asked questions

Does Title Case capitalize small words like "the" and "of"?

This converter capitalizes every word for simplicity and consistency. Some style guides lowercase minor words like "a," "the," and "of" in titles, check your specific style guide if that distinction matters for your use case.

Is my text saved anywhere?

No, all conversion happens locally in your browser. Nothing is sent to a server.

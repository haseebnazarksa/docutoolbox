What is the Text Differ?

This tool compares two blocks of text line by line and highlights exactly what changed between them, lines removed from the original are shown in red, lines added in the new version are shown in green, and unchanged lines appear as plain text.

How to use it

  1. Paste your original text into the left box.
  2. Paste the changed text into the right box.
  3. Click Compare text to see a line-by-line diff.

How the comparison works

The tool compares text line by line, using a standard diff algorithm to find the longest matching sequence of unchanged lines between the two versions, then marks everything else as either added or removed. This is the same basic approach used by version control tools like Git to show changes between file versions.

Common uses

  • Reviewing edits made to a document or article between drafts
  • Comparing two versions of code, configuration files, or data exports
  • Checking exactly what changed in a contract or legal document revision
  • Spotting subtle differences between two similar pieces of text

Frequently asked questions

Does this compare word by word or line by line?

This tool compares line by line, if a single word changes within a line, the entire line is marked as changed (shown as one removed line and one added line) rather than highlighting just the changed word.

Is my text uploaded anywhere?

No, the comparison runs entirely in your browser using JavaScript.

What is this tool?

This tool generates the essential meta tags every webpage needs for search engines and social media, the page title, meta description, and Open Graph / Twitter Card tags that control how a page's preview looks when shared on Facebook, X, LinkedIn, or search results.

How to use this tool

  1. Enter your page's title, description, URL, and an image URL for social sharing.
  2. Check the live Google search preview to see how it will appear.
  3. Copy the generated code and paste it into your page's <head> section.

Meta tag length guidance

  • Title - keep under 60 characters, longer titles get truncated in search results
  • Description - keep under 160 characters for the same reason
  • Image - use a full, absolute URL (starting with https://), relative paths won't work when the page is shared externally

Frequently asked questions

Do these tags guarantee better search rankings?

No, meta tags help search engines and social platforms understand and display your page correctly, but they don't directly boost rankings, ranking depends on many other factors like content quality and backlinks.

What's the difference between Open Graph and Twitter Card tags?

Open Graph tags (prefixed og:) are used by Facebook, LinkedIn, and most platforms, while Twitter Card tags (prefixed twitter:) are specific to X (Twitter), this tool generates both so your page looks correct everywhere it's shared.

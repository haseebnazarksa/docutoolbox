What is the Image Resizer?

The Image Resizer changes the pixel dimensions of an image, either to an exact width and height you type in, or to a percentage of the original size. With the aspect ratio locked, changing one dimension automatically adjusts the other, so your image never comes out stretched or squashed.

Everything happens locally in your browser using the Canvas API. Your image is never uploaded to a server, so it's fast and private, and there's no file size charged against a quota.

How to use it

  1. Drop your image onto the upload area, or click it to browse your device.
  2. Use the quick 25% / 50% / 75% / 100% buttons for a fast percentage resize, or type an exact width or height into the fields.
  3. Leave "Lock aspect ratio" checked so the other dimension updates automatically and your image stays proportional.
  4. Optionally choose an output format and, for JPG or WEBP, a quality level.
  5. Click Resize image and download your result.

Exact dimensions vs. percentage resizing

Use exact dimensions when you know precisely what size you need, such as a 1200×630px image for a social media banner, or an 800px-wide product photo for a website. Use percentage resizing (the 25/50/75/100% buttons) when you just want to shrink an image by a proportional amount without worrying about the exact pixel count, like halving a photo's size before sharing it.

Why the aspect ratio lock matters

Every image has a natural width-to-height ratio. If you resize only the width without adjusting the height to match (or vice versa), the image gets stretched or squashed and looks distorted. With the lock enabled, typing a new width automatically calculates the matching height (and the reverse), so the image always keeps its original proportions no matter what size you choose.

Choosing an output format

  • Keep original format (default) - outputs the same file type you uploaded
  • JPG - smaller file size, ideal for photos, with adjustable quality
  • PNG - lossless, best for graphics, screenshots, or images needing transparency
  • WEBP - modern format offering strong compression with good quality, supported by all current browsers

How it works technically

The tool loads your image into an in-browser canvas at the target dimensions, letting the browser's own high-quality image scaling handle the resize, then exports the result as a new image file in your chosen format and quality. This is the same underlying technology used by professional image editing tools for resizing.

Common uses

  • Shrinking a large photo before uploading it to a website with a file size limit
  • Resizing an image to exact dimensions required by a social media platform or ad specification
  • Making a smaller thumbnail version of a larger image
  • Preparing product photos to a consistent size for an online store
  • Reducing image dimensions to speed up a webpage's load time

Frequently asked questions

Will resizing reduce my image's quality?

Reducing dimensions (making an image smaller) generally looks sharp, since there's more detail than needed for the smaller size. Increasing dimensions beyond the original size can make an image look softer, since new pixels are being estimated rather than captured originally.

What happens if I uncheck "Lock aspect ratio"?

You can then set width and height independently, which lets you deliberately stretch or squash an image if that's what you need, though for most uses keeping the lock on gives a natural-looking result.

Can I resize to a larger size than the original?

Yes, though enlarging an image beyond its original resolution will look less sharp than the source, since no new detail is actually being added.

Does this tool preserve transparency in PNG images?

Yes, transparent areas in a PNG stay transparent after resizing, as long as you keep the output format as PNG (JPG does not support transparency).

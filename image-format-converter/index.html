What is the Image Format Converter?

This tool converts an image between eight formats, JPG, PNG, WEBP, BMP, TIFF, GIF, SVG, or PDF, right in your browser, with an optional resize built in so you can change the file type and dimensions in one step.

Everything happens locally using the Canvas API. Your image is never uploaded to a server, so it's fast and private.

How to use it

  1. Drop your image onto the upload area, or click it to browse your device.
  2. Choose the format you want to convert it to.
  3. Optionally resize it, by exact pixels or by a percentage, before converting.
  4. For JPG, WEBP, and GIF, adjust the quality slider if needed.
  5. Click Convert image to see the before/after file size comparison.
  6. Download your converted file.

A note on GIF: since it supports a maximum of 256 colors, photos are automatically reduced to their closest 256-color match, which works well for simple graphics and icons but shows visible color banding on complex photographs. A note on SVG: SVG is a vector format, and a photo can't truly become vector art, so this option embeds your original image data inside a valid SVG file, useful when a tool or platform specifically requires an .svg file extension.

Why convert between formats?

  • Converting a PNG screenshot to JPG to shrink its file size when transparency isn't needed
  • Converting a photo to PDF to attach it to a document or print it
  • Converting to TIFF or BMP for older desktop software that expects those formats
  • Converting to WEBP for a faster-loading website
  • Resizing an image to exact dimensions while also changing its format, in a single step

How it works technically

The tool loads your image into an in-browser canvas, applies any resize you've set, then re-encodes the pixel data into your chosen format. JPG, PNG, and WEBP use the browser's built-in encoder, while BMP, TIFF, GIF, SVG, and PDF are assembled directly in JavaScript following each format's file specification. Everything runs on your device, nothing is uploaded anywhere.

Frequently asked questions

Why isn't HEIC available as an output format?

HEIC is a patent-encumbered format that no web browser can encode client-side, any tool claiming to convert to HEIC in your browser is quietly producing a JPG or PNG with a renamed file extension. We'd rather leave it out than mislead you.

Will converting to JPG lose my image's transparency?

Yes, JPG, BMP, and TIFF here do not support transparency, so any transparent areas are filled with white. PNG, WEBP, GIF, and SVG all preserve transparency.

Does resizing distort my image?

Only if aspect ratio lock is off and you set a width and height that don't match the original proportions. Keep the lock on to resize without distortion.

Is my image uploaded anywhere?

No, all conversion happens locally in your browser using the Canvas API, nothing is sent to a server.

What is a user agent string?

A user agent string is a piece of text that every web browser sends with each request, identifying the browser, its version, the operating system, and device type. Websites and servers use this information for compatibility checks, analytics, and content adjustments. This tool parses any user agent string into readable, labeled information.

How to use this tool

  1. Paste a user agent string into the box, or click Use my current browser's UA to load your own.
  2. Click Parse user agent.
  3. Review the identified browser, OS, and device type.

Common uses

  • Debugging a browser-specific bug by identifying exactly which browser and version a user reported it from
  • Checking what a server log's user agent string indicates about a visitor
  • Verifying how your own site's analytics or bot detection identifies a given browser
  • Understanding an unfamiliar user agent string found in logs or documentation

Frequently asked questions

Why does my browser's actual user agent look different from what I expect?

Many modern browsers include legacy compatibility tokens (like "Mozilla/5.0") for historical reasons, and some browsers deliberately obscure or freeze parts of their user agent string for privacy, this is expected behavior, not an error.

Is user agent parsing 100% reliable?

Not perfectly, user agent strings can be spoofed or modified by the user or browser extensions, and detection relies on pattern matching against known formats, which may not catch every edge case or newer browser version.

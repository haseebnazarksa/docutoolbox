What is this tool?

This tool converts colors between the three formats most commonly used in web design and CSS: HEX (like #C9A227), RGB (like rgb(201, 162, 39)), and HSL (like hsl(45, 68%, 47%)), with a live color preview.

How to use this tool

  1. Use the color picker, or type a HEX code directly into the text field.
  2. All three formats and the preview update instantly.
  3. Click Copy next to any format to copy that value.

Understanding the formats

  • HEX - a six-digit hexadecimal code representing red, green, and blue values, the most common format in CSS and design tools
  • RGB - red, green, and blue values from 0-255, sometimes easier to reason about numerically
  • HSL - hue, saturation, and lightness, often more intuitive for adjusting a color's shade or brightness

Frequently asked questions

Can I use RGBA or HSLA for transparency?

This tool converts solid colors, for transparency, add an alpha value to the RGB or HSL output manually, for example rgba(201, 162, 39, 0.5) for 50% opacity.

Which format should I use in my CSS?

All three are equally valid and supported everywhere, HEX is the most common convention for solid colors, while HSL is often preferred when you need to programmatically adjust lightness or saturation.

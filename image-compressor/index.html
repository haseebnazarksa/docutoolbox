What is the Image Compressor?

The Image Compressor shrinks your photo file sizes dramatically while keeping them looking sharp. Upload one image or dozens at once, each one compresses automatically using a quality setting tuned to cut file size by 60-80% with almost no visible difference, and you can fine-tune any image individually if you want more or less compression.

Everything runs locally in your browser, your images are never uploaded to a server, so it works instantly and keeps your photos private.

How to use it

  1. Drop your images onto the upload area, or click it to browse, select as many as you need at once.
  2. Each image compresses automatically the moment it's added, keeping its original format (a PNG stays PNG, a JPG stays JPG) at 82% quality, a setting chosen to give a big size reduction with barely any visible loss.
  3. Change the format dropdown on any image (WebP, JPEG, or PNG) if you'd rather have a different output type, WebP usually gives the smallest file size.
  4. See the before and after file size, plus the percentage saved, for every image.
  5. Drag any image's slider to compress it more or less, or change the output format per image.
  6. Use "Apply to all images" if you change the format or quality and want every image updated the same way.
  7. Download images individually, or click Download all (.zip) to get everything in one file.

Why WebP gives you the best results

WebP is a modern image format that typically produces files 25-35% smaller than JPEG at the same visual quality, and it also supports transparency like PNG, unlike JPEG. By default, each image keeps its original format so nothing changes unexpectedly, but switching any image to WebP from its dropdown usually gives you the smallest possible file size without a visible drop in quality. JPEG remains available for maximum compatibility with older software, and PNG compresses using color quantization, the same technique tools like TinyPNG use, keeping transparency and sharp edges intact while still shrinking the file.

Finding the right balance

Quality above 80% is usually visually indistinguishable from the original for photos, while cutting file size significantly. Going below 50% starts to introduce visible blurring or blocky artifacts, especially in photos with fine detail. The default of 82% is chosen as a strong starting point, but every image is different, use the before/after preview and the slider to find what looks right for your specific photo.

Frequently asked questions

Will compressing reduce my image's visible quality?

At the default 82% quality, most photos show no noticeable difference to the eye, even though the file size drops significantly. You control the exact trade-off with the quality slider on each image.

What's the difference between WebP, JPEG, and PNG here?

WebP and JPEG are both "lossy" formats that trade a small amount of quality for a much smaller file size, WebP does this more efficiently than JPEG. PNG here uses color quantization, reducing the number of unique colors in the image (256 down to 32, depending on the quality slider) instead of blurring pixels, this is the same approach pngquant and TinyPNG use, and it keeps transparency and sharp edges fully intact.

Can I compress a lot of images at once?

Yes, there's no fixed limit, upload as many as you need and each one compresses independently, then download them all together as a single zip file.

Is my image data uploaded anywhere?

No, all compression happens directly in your browser using the Canvas API, your images never leave your device.
